# EventConnect Ghana

## Overview

EventConnect Ghana is an event services marketplace that connects
customers with service providers in Accra, Ghana.

Customers can discover professionals, compare services, and submit
booking requests directly through the platform.

Service providers can create business profiles, publish services,
manage booking requests, and send quotations.

Administrators manage provider approvals, categories, reports,
and platform quality.

## Target Market

Initial launch: Accra, Ghana.

Future expansion: Other cities and regions across Ghana.

## User Roles

- Customers
- Service Providers
- Administrators

## Core Features

- User registration and authentication
- Provider profiles and service listings
- Service categories and search
- Location-based filtering
- Booking requests
- Provider quotations
- Booking status tracking
- Customer reviews

- Administrative dashboard

## Initial Business Model

The initial platform will allow customers to submit booking requests
without paying the platform.

Online payments and paid provider subscriptions are planned for
future releases.
